プライバシーポリシー

最終更新日：2026年5月21日

本アプリ「STICK QUEST」（以下「本アプリ」）をご利用いただきありがとうございます。本ポリシーでは、本アプリが取り扱う情報について説明します。

1. 収集・送信する情報

  • お客様が選択した画像：棒の鑑定機能を利用する際、お客様がフォトライブラリから選択した画像をGoogle Gemini API（Google LLC）に送信します。送信した画像は当方のサーバーには保存されません。
  • 広告識別子・端末情報：広告配信のため、LevelPlay（IronSource Ltd.）が広告識別子等の情報を収集します。
  • 購入情報：アプリ内課金はApple Inc.のApp Store経由で処理されます。当方はお客様の決済情報を受け取りません。
  • ゲーム進行データ：武器データ・ステージ進捗・設定などはお客様の端末内にのみ保存され、外部に送信されません。

2. 情報の利用目的

  • 棒の鑑定結果の生成
  • 広告の配信
  • アプリ内課金の処理
  • 不正利用の防止（Firebase App Check）

3. 利用する第三者サービス

本アプリは以下のサービスを利用しています。各サービスのプライバシーポリシーもご参照ください。

  • Google（Gemini API / Firebase）
  • IronSource Ltd.（LevelPlay）
  • Unity Technologies（Unity IAP）

4. フォトライブラリへのアクセス

鑑定機能の利用時にフォトライブラリへのアクセスを求めます。選択した画像は鑑定目的のみに使用され、端末外に保存されることはありません。

5. 年齢について

本アプリは13歳未満のお客様から意図的に個人情報を収集しません。

6. プライバシーポリシーの変更

本ポリシーは予告なく変更される場合があります。変更後のポリシーは本ページに掲載します。
